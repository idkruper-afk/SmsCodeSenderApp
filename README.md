# SMS Code Sender Android App

An Android application that sends pre-configured or custom SMS codes directly to any mobile number with a single button tap using Android's `SmsManager`.

## Features
- **Auto-Saved Target Mobile Number**: Enter the destination phone number once and the app remembers it automatically.
- **6 Programmable One-Tap Code Buttons**: Tap any button to immediately transmit its SMS code. **Long-press** any button to edit its name and the exact SMS code it sends.
- **Custom Code Input**: Send one-off codes at the bottom without overwriting your presets.
- **Live Delivery Status**: Confirms when the cellular network accepts the SMS.
